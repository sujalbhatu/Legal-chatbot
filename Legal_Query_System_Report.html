Multilingual Legal Query System

Technical Specification & Architecture Report

Executive Summary

The Multilingual Legal Query System is a sophisticated Retrieval-Augmented Generation (RAG) platform designed to democratize access to Indian Law. It enables citizens and legal professionals to query a localized database of Indian Acts using 14 regional languages, providing high-precision, well-cited legal advice through a hybrid AI architecture.

Technology Stack

Large Language Model (LLM) Groq Engine (Llama-3.3-70B / GPT-OSS-20B)
Embedding Model law-ai/InLegalBERT (State-of-the-Art Legal Transformer)
Vector Database ChromaDB (Persistent Document Storage)
Frontend & Backend React.js, Node.js (Express), and Python (Flask)

Architecture & Data Flow

[User Query: Bengali] -> [LangDetect] -> [Translator] -> [English Intent] | v [ChromaDB] <- [Vector Match / Intent-Pivoting Booster] <- [InLegalBERT] | v [Top 8 Legal Chunks] -> [Context Generator] -> [Groq LLM] | v [Cited Response in Bengali] <- [Prompt Injection (User Language)]

Key Components

  • InLegalBERT Specialization: Unlike generic models, our embeddings are pre-trained on Indian High Court and Supreme Court judgments.
  • Intent-Pivoting Logic: A secondary retrieval layer that force-fetches specific laws (e.g., CGST, POCSO) by metadata if semantic scores are low.
  • The Translation Bridge: A custom logic that uses English as a high-fidelity intermediate language for legal research while maintaining native-language responses.
